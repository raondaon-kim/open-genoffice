# K12 학교 양식 소스 후보 및 반영 기준 (연구 노트)

이 문서는 "실제 학교 현장 디자인 양식"을 Open GenOffice(공개 저장소)에 반영하기 위한
후보 소스와 라이선스 검증 기준을 정리한 노트다. 실제 파일 배포는 아래 기준을 모두 통과한
것만 포함한다.

## 후보 소스 (조사 2026-09)

- 무료 학교용 서식 모음: http://www.freeforms.co.kr (학교용/가정통신문/학습지도안 등)
  - 주의: 사이트 이용약관에 재배포 조건 명시 확인 필요
- 교육청·학교 홈페이지 게시판(시도교육청, 지역교육지원청): 예) 전북교육청 school.jbedu.kr,
  익산교육지원청 저작권정책 페이지(https://school.jbedu.kr/jbise/M01010204/index.do)
  - 시도교육청이 공공누리 등으로 공개한 양식은 출처표시 조건으로 재사용 가능 후보
- 교사 공유 자료(블로그/티칭허브 등): 개별 저작권·재배포 허락 필요
- 글꼴: 케리스 학교 안심폰트(https://www.ktv.go.kr/news/major/view?content_id=740277) —
  문서 제작용 무료 폰트(재배포 조건 별도 확인)

## 반영 전 필수 검증 체크리스트

1. 라이선스/출처: 공공누리 유형 또는 재배포 명시 허용. 출처 표기 요구 시 팩 내
   SOURCES.md에 기재
2. 식별 정보 제거: 학교명·로고(교표)·교사/학생 실명·전화·주소 등 → 자리표시자
   ({학교명}, ○○초등학교 등)로 대체
3. 형식 변환·정합: .hwp(구형)는 HWPX 변환 또는 rhwp 재인코딩, 실제 한글에서 여는지
   수동 검증(레거시 .hwp는 rhwp가 읽는 것만 취급)
4. 기술 검증: 각 파일을 rhwp 스튜디오에 로드(page≥1, 오류 0) + 본 앱 스크린샷 점검

## 반영 방식 (2단계)

- 지금(진행 중): Markdown 템플릿으로 "실제 학교 문서 구조 재현" —
  문서번호/발신·수신/로고 자리/결재란/안내 하단을 갖춘 .hwpx 생성 (예: 가정통신문 디자인형)
- 이후: 검증 통과한 원본 .hwpx 라이브러리(복사-열기 방식)와 자리표시자 자동 입력 UX

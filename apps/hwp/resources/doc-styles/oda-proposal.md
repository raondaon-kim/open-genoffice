# 국내 ODA 사업 제안서 (한글, KOICA·EDCF)

KOICA(한국국제협력단)·EDCF(한국수출입은행 대외경제협력기금) 사업수행기관·컨설팅 입찰에 내는 국문 제안서의 서식 초안입니다. 골격은 **표지 → 조견표·목차 → 장(Ⅰ~Ⅳ)과 절·항목** 이며, 장 구성과 분량은 언제나 **해당 제안요청서(과업지시서)의 제안서 목차와 분량 비율**을 따릅니다.

- **KOICA 표준 목차 (PMC·프로젝트형, 2025):** Ⅰ 제안사 소개(≤10%) → Ⅱ 기술 부문(≤50%: 1. 사업이해도 — 차별성, 대상지 As-is/To-be, 현지화 전략, Goal–Outcome–Output–Activity 논리 / 2. 세부실행방안 — 기본방향, 전문가 파견, 연수생 초청, 기자재, PDM 기반 활동) → Ⅲ 사업관리 부문(≤30%: 투입인력·조직, 성과관리, 일정, 위험·안전, 사후관리, 품질, 홍보) → Ⅳ 제안내용 고도화(≤10%) → 첨부.
- **EDCF 표준 목차 (PMA·F/S, 수출입은행 발주):** Ⅰ 과업 이해(목적, 범위, 대상국, EDCF 절차) → Ⅱ 수행계획(전략, 구성요소별 접근방법·위험·성과품) → Ⅲ 조직·인력 → Ⅳ 성과·품질 제고 아이디어 → 첨부 서식.
- **단계 부호:** `Ⅰ.`(장, 16pt 굵게) → `1.`(절, 13pt 굵게) → `1-1.`(13pt 굵게) → `가.`(13pt) → `o`(13pt) → `-`(13pt) → `*`(주석 12pt). 본문 13pt, 줄간격 160%, 개조식. KOICA·EDCF 제안요청서의 서식 규정과 같습니다.
- **쪽 설정:** A4 세로, 여백 좌우 25mm·위 20mm·아래 15mm, 쪽번호 아래 가운데. 표 안 글자는 12pt(줄간격 130~145%).
- **ODA 제안서에서 꼭 지킬 것:**
  - 모든 활동을 PDM(목표–성과–산출–활동–투입)의 산출물·성과에 연결합니다.
  - 성과지표마다 산식, 기초선, 목표치, 검증수단을 적고 성별로 나눕니다.
  - 범분야 이슈(성평등, 취약계층·장애, 환경, 인권, 아동보호)를 활동에 반영합니다.
  - 현지 파트너와 수원국 오너십, 지속가능성과 출구전략(사후관리)을 씁니다.
  - 위험은 가능성×영향 매트릭스(1~5등급)로, 인력 안전을 포함합니다.
  - 주장은 자료로 뒷받침하고(KOICA 분석상 "데이터 기반" 계획이 당락을 가름), 약어는 처음 나올 때 풀어 씁니다.
  - "~할 수 있다" 대신 "~한다"로 확정해 씁니다(제안 내용은 계약상 이행 의무).
  - 제안사 실적·신용등급·인력·현지 협력기관 같은 사실은 지어내지 않고 [회사 실적 기재] 같은 자리표시로 둡니다.

**확인이 필요한 값 (초안):** 실제 제출 제안서는 비공개라 KOICA·EDCF 제안요청서의 서식 규정(줄간격 160%, 여백 25/20/15mm, Ⅰ. 16pt, 1. 13pt, 본문 13pt)과 KOICA 공식 제안서 양식에서 잰 값으로 만들었습니다. 사내 과거 제안서로 확인하면 이 표시를 지웁니다.
